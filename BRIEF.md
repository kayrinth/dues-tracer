# Iuran Tracker Website — Project Brief

---

# Project Name

Iuran Tracker

---

# Overview

Iuran Tracker is a web-based application built using Next.js and Supabase to help users manage and monitor monthly household or shared-property payments.

The system allows users to track recurring utility payments such as:

- Waste + WiFi
- Electricity Upstairs
- Electricity Downstairs

The application is designed to simplify bookkeeping, automate total calculations, and provide organized monthly payment records.

---

# Project Goals

- Simplify monthly contribution management
- Reduce manual calculation errors
- Provide organized payment records
- Enable fast and responsive data management
- Create a modern and scalable web application

---

# Target Users

- Boarding house owners
- Shared house residents
- Family households
